How it works

  1. Hold an Agent ID. The contract checks on-chain whether your wallet holds an Agent ID. No ID, no claim.
  2. Claim. Pick a live campaign. The site fetches your 4-digit anti-bot code from the contract and fills it in — one click, free apart from network gas.
  3. Keep your badge. Each claim mints an ERC-721 badge to your wallet. It is a collectible, not an investment.

The 4-digit code is a lightweight speed bump against naive bots — it is readable on-chain by anyone, so it is not strong bot-proofing and we do not present it as such. Campaigns are created by anyone and are not endorsed by AgentClaim.
